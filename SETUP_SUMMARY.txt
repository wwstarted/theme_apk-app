## 🚀 Quick Start (for WordPress Admin)

### 1. Install WooCommerce
Menu → Plugins → Add New → Search "WooCommerce" → Activate

### 2. Create Categories
Menu → Products → Categories → Add:
- **Game** (slug: game)
- **App** (slug: app)

### 3. Add Products
Menu → Products → Add New → Fill in:
- Title, Description, Featured Image
- Category: Game/App
- **Download URL** metabox: paste link
- **Product Rating** metabox: enter 0-5 value
- Publish

### 4. Add to Homepage

**Option A - Shortcode (Easiest):**
```
[vy_products_grid title="GAME Mới Cập Nhật" category="game" per_page="12"]
```

**Option B - PHP in front-page.php:**
(See WOOCOMMERCE_README.md for full code)

## 🔧 Key Functions Available

## ⚙️ Customization Options

### Colors (edit `woocommerce-products.css`):
```css
:root {
    --apk-btn-bg: #58C21C;           /* Button green */
    --apk-btn-hover: #a2d43c;        /* Hover green */
    --apk-title-color: #333;         /* Product title */
    --apk-category-color: #666;      /* Category text */
}
```

### Grid Spacing:
```css
--apk-gap: 20px;                     /* Space between items */
--apk-border-radius: 8px;            /* Card corners */
```

### Shadow & Hover:
```css
--apk-item-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
--apk-item-hover-shadow: 0 4px 16px rgba(0, 0, 0, 0.15);
```

## 🆘 Important: Star Rating Icons

You MUST upload these images to `/images/` folder:
- `star.png` (filled star, 16-32px)
- `star-empty.png` (empty star, 16-32px)

**OR** modify `vy_get_product_star_rating()` to use FontAwesome icons:
```php
// In vy_get_product_star_rating(), replace image output with:
<i class="fa-solid fa-star"></i>  // filled
<i class="fa-regular fa-star"></i> // empty
```
